# 和序 HIS 界面说明

按用户要求使用 shadcn/ui，并按 2026-10-29 确认的参考基调重做界面：白色底、淡紫蓝渐变、近黑文字与胶囊主按钮、20～24px 圆角卡片、细边框和大量留白。不再使用旧版深青侧栏与绿色主操作。

## 视觉基调

- 背景为 `#fafafc`，顶部叠加淡紫与淡蓝径向渐变；内容区保持大面积留白。
- 侧栏为半透明白色、细右边框，当前菜单使用淡紫底与蓝紫文字；顶部栏半透明并带轻模糊。
- 主按钮为近黑色胶囊，次按钮为浅灰胶囊，描边按钮为白底细边框；强调色使用蓝紫 `#5b6bff`。
- 卡片圆角 20～24px，边框 `#ececf1`，阴影很浅；工作台首张指标卡和快捷卡片使用淡紫/淡蓝渐变。
- 表格无重色表头，使用浅灰表头、细分隔线和低对比悬停色。
- 登录页为居中标题、上方渐变光晕、白色登录卡片和三张能力说明卡；错误与成功提示保持轻量圆角色块。

## 本版可见内容

- 登录：演示身份快捷填入、登录错误提示、虚构数据声明。
- 工作台：按角色显示今日待办/业务指标、快捷入口和门诊流程图；管理员额外显示近7日趋势。
- 接诊看板：今日候诊/接诊中/已完成分区、排队号、实时时钟、开始接诊和进入诊疗；今日挂号按日期查询，不再从最近100条中客户端过滤。
- 处方管理：状态筛选（全部/草稿/待收费/已收费/已发药/已退费）、患者搜索、草稿编辑、明细弹窗、提交和打印。
- 开方表单：常用诊断检索、多药明细；药品下拉显示未过期可用库存，可用量为0的药品不可选。
- 收费与发药：待办队列、患者搜索、明细核对弹窗、收费方式、确认收费/发药；发药页可切换待发药与已发药。
- 收费记录与退费：状态筛选、凭证打印、全额退费弹窗、原批次回库提示。
- 挂号：患者搜索、状态筛选、取消挂号二次确认；医生仅见本人患者。
- 药品与库存：总库存与可用库存分列，批次效期和过期提示；库存预警/流水、经营图表和打印单据保持原有能力。
- 账号与角色：角色中文名、启用/禁用状态徽章、禁用确认弹窗。
- 审计日志：动作中文名称、原始动作代码、展开变更详情。

## 交互与数据改进

- 收费、发药、退费和账号禁用使用页面内模态框，支持 Esc 与点击遮罩关闭，不新增弹窗依赖。
- 列表使用骨架加载行和空状态；错误提示根据 400/401/403/404/409/0 给出更具体的标题。
- 后端查询新增挂号日期/状态筛选、处方患者关键字筛选；药品分页批量聚合未过期库存，避免逐条查询。
- 工作台统计按角色补充分项：管理员待收费/待发药，医生今日候诊/就诊中/已完成，收费员今日挂号/收费/退费，药师今日发药。
- 视觉上仍保持原有业务不变量：金额后端计算、收费与库存同事务、仅草稿可编辑、未发药可全额退费、医生仅处理本人业务。

## 组件与许可

使用 https://ui.shadcn.com/ 官方 New York v4 registry 的 Button、Input、Textarea、NativeSelect、Table、Card、Badge、Skeleton 源码，MIT 许可。代码在 `frontend/src/components/ui`，来源及依赖许可见 `frontend/THIRD_PARTY_NOTICES.md`。

侧栏、业务布局、Modal、SVG 图表为项目实现。使用现有 Tailwind CSS v4、Radix Slot、class-variance-authority、clsx、tailwind-merge 和 lucide-react，本轮未安装新依赖。
