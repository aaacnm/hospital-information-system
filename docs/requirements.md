# 选题、范围与功能验收
选题：基于《医院信息系统基本功能规范》的门诊业务闭环系统。
依据：老师第 4～12 课及老师“依据 2002 年规范选择题目，提交代码、PPT、相关文档”的要求。选定门诊医生工作站、门诊收费、门诊药房的部分功能；支持患者与挂号流程。本轮由用户授权自行选范围，不再等待教师回复，不要求公网地址。

这是课程功能主题对应表，未取得完整规范原文核验，不编造条款编号，不声称完成规范全文合规认证。
| 规范功能主题 | 本项目实现 | 验收 |
|---|---|---|
| 门诊医生工作站：诊疗/处方 | 本人待诊、诊断编码/名称、多药明细、草稿编辑与提交 | 别人的挂号不能开方；开方自动划价 |
| 门诊收费：划价/收费记录 | 后端金额、单价快照、待收费队列、原子收费 | 修改前端金额无效；重复收费 409 |
| 门诊药房：药品/库存/发药 | 药品五要素、批次入库、效期、先到期先出、已收费发药 | 库存不足整笔回滚；发药不重复扣库 |
| 支撑：患者/排班挂号 | 虚构患者建档与搜索、未来7天排班、挂号与取消 | 号源变化、排队号唯一 |
| 共有：权限与审计 | 四角色、401/403、自动与语义留痕、按人/动作/日期查日志 | 发药后可查到刚才操作 |
| 数据质量与统计 | CSV 校验/去重/部分成功、今日统计、汇总导出 | 坏行有行号；今日金额与收费单一致 |
| 工程质量 | 迁移、初始化、测试、构建、本机启动、可选 Docker/CI | 从空演示库可复现 |
| AI 加分 | 结构化分诊、10秒超时、外发身份信息拦截、免责声明 | 默认关闭不外发，失败明确待人工评估 |

## 明确不实现及原因
不实现住院、真实医保/支付、PACS、电子病历全文、完整预约分诊、区域平台/FHIR联调。它们超出选题部分功能与本机课程验收。
不实现完整药库采购、供应商和盘点；当前为门诊药房批次入库/出库子集。
不承诺生产医疗安全或高并发能力；教学药品、诊断与用法不是医疗建议。

## 验收路径
收费员：患者选择 → 当日医生排班 → 挂号。
医生：本人待诊 → 多药处方 → 核对自动金额 → 提交。
收费员：待收费 → 核对患者/明细/金额 → 收费。
药师：已收费 → 核验 → 发药。
管理员：报表、库存批次、刚才的收费/发药审计；越权现场返回403。
