# 功能范围与验收清单

依据老师第4～12课课件及“根据2002医院信息系统功能规范选择题目”的要求，选取门诊医生工作站、门诊收费、门诊药房的部分功能。用户明确要求本机演示、可见功能优先，不需要公网地址。未取得规范全文逐条核验，不编造条款编号。

| 功能 | 页面与可见结果 | 权限/关键边界 |
|---|---|---|
| 患者档案与排班挂号 | 搜索患者、选择医生时段、生成排队号、剩余号源变化 | 医生仅见本人关联患者，接诊前可取消 |
| 接诊看板 | 实时时钟、候诊/接诊/完成分区、开始接诊、进入诊疗 | 最近100条中的今日记录，医生仅本人 |
| 诊疗记录 | 主诉、现病史、既往史、过敏史、查体，教学示例与保存提示 | 医生填写，提交处方后锁定 |
| 常用诊断 | 按名称/编码检索并选择，可手动录入 | 12项ICD-10教学示例，不是完整字典 |
| 患者时间线 | 日期、医生、诊断、主诉、金额和处方入口 | admin/doctor，医生仅本人接诊 |
| 多药处方 | 创建/编辑草稿、自动金额、提交、处方打印 | 仅草稿可改，单价快照 |
| 收费与凭证 | 待办核对、收费方式、成功提示、收费记录搜索、打印 | 教学记账，不连真实支付 |
| 未发药退费 | 原凭证保留、退费原因、已退费标记、原批次回库 | 仅已收费未发药，本轮完整出库记录 |
| 药房发药 | 仅已收费队列、核对患者药品、确认发药 | 不重复扣库存，重复操作被拒绝 |
| 库存预警与流水 | 低库存/近效期/过期筛选，账面/可用量，批次出入库记录 | admin/pharmacist；过期量不能出库 |
| 经营图表 | 日期筛选、4项指标、双趋势、科室分布、每日明细、CSV | admin；最大90天，收费减退费为净额 |
| 数据与管理 | 药品CSV校验/去重/部分成功、审计筛选、账号启停 | 管理权限，导入最大2MB/5000行 |
| 展示场景 | 7天虚构业务、多医生、患者、预警和不同状态待办 | 独立演示库，禁止覆盖已有业务 |

验证分为自动检查、API读取和浏览器实际操作。前两类本版已有结果，用户选择将新页面浏览器验收延后，见[test-report.md](test-report.md)。

不包含住院、真实医保/支付、PACS、区域平台、完整ICD字典、完整电子病历认证或药库采购盘点。AI默认关闭，未验证真实外部模型。
