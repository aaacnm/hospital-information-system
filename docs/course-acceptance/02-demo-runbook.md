## 答辩必答点

- 金额由后端根据药品单价和数量重新计算，前端金额不可信。
- 收费、处方状态和库存扣减在同一事务内，失败整体回滚。
- 号源和排队号由后端控制，冲突返回 409。
- 前端隐藏按钮不是权限边界，后端依赖返回 401/403。
- AI 分诊只返回辅助建议和免责声明，不创建处方、不收费、不扣库存。

## 现场注意事项

- 每次演示使用独立或重置后的 SQLite 数据库。
- 不展示真实姓名、身份证、手机号、JWT、API key 或数据库连接串。
- 不能运行的 Docker 或 CI 步骤要直接说明“待补证据”，不能用录屏替代。
