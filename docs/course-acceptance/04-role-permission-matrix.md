## 必测状态码

| 场景 | 预期 | 实际/证据 |
|---|---|---|
| 错误密码登录 | 401 | 待填 |
| 无 token 访问 `/api/auth/me` | 401 | 待填 |
| 收费员访问 `/api/admin/ping` | 403 | 待填 |
| 药师访问改价或收费 | 403 | 待填 |
| 医生访问审计日志 | 403 | 待填 |

异常状态码 400/409 还应在业务闭环记录中填写；不要只验证前端按钮是否隐藏。
