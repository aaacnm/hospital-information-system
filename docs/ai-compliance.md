# AI 功能合规自查
| 项目 | 实际边界 |
|---|---|
| 功能 | 已登录用户的辅助分诊；不创建处方，不决定用药与收费 |
| 输入 | 最多2000字符的症状字段；页面最多1000；只允许虚构数据 |
| 输出 | 建议科室、紧急程度、说明、免责声明、来源 |
| 科室 | 返回必须来自当前启用科室，不能接受模型任意值 |
| 失败 | 10秒超时、错误JSON、服务不可用、身份信息模式、明显提示注入均本地兜底 |
| 兜底 | 待人工评估，提示联系分诊；不把“普通”当作排除急症 |
| 用户告知 | 界面明确AI生成、仅供参考、需医生确认；急症立即寻求急救 |
| 外部调用 | 默认AI_PROVIDER=disabled，不依赖付费接口；本次没有真实外部调用 |
| 日志 | 只记录来源与科室，不写症状原文或身份信息 |
配置外部provider必须由操作者提供有效密钥与授权；密钥只放环境变量。正则拦截无法证明任意文本都已匿名，不使用真实临床资料。
测试用假provider验证正常结构、超时、错误、注入与身份信息拦截；不能把这些测试称为真实模型质量验证。
