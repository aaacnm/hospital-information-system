# 浏览器主流程验收

本轮按工作区要求仅用Chrome DevTools MCP操作浏览器。实际记录见 [主线记录](evidence/browser-mainline.md)。
收费员选择患者与当日排班挂号；医生从本人待诊进入开方，药甲2份、药乙1份，后端划价28.00；提交后收费员核对收费；药师核对并发药；管理员核对审计与今日汇总。过程无需手填ID。

仓库 `tests/e2e/flow.spec.ts` 已适配新界面和两药金额，后端由正常迁移/seed准备隔离临时数据库。脚本供有授权的CI运行，本轮没有在本机另启Playwright，也未生成本次Playwright trace或视频。

异常行为由API与并发测试覆盖，包含越权、库存不足、重复收费、提前/重复发药和号源争抢。浏览器文字记录不代替这些自动断言；截图不可用如实标明，不以设计图替代。
