# 现场演示手册

1. 在项目根目录执行start-demo.ps1（需重建时加-Build），打开127.0.0.1:8000。
2. 收费员选患者、今日医生排班，确认挂号，展示排队号和余号变化。
3. 医生打开本人待诊，添加两种药，检查后端金额并提交处方。
4. 收费员核对待收费队列并收费，药师核对已收费队列并确认发药。
5. 管理员展示库存、今日统计、收费和发药审计；说明角色与事务限制。
6. 演示结束在启动终端Ctrl+C，检查端口退出。

统一虚构演示密码Demo123!；具体账号、5+2分钟安排与问答见 [主脚本](../demo-script.md)。不要照抄本轮处方ID，现场按页面列表选择。
